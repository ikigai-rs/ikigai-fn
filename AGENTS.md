# AGENTS.md

`ikigai-fn` is a library of reusable ikigai function endpoints: template composition (`compose`,
`each`, `conditional`), small text functions, and `ikigai_fn::html`, the shared HTML escaping and
link rules.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-fn/security/advisories/new), never a public
  issue.
- Use American spelling (behavior, color, labeled, artifact).
